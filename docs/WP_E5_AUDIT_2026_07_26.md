### A-2 — CRITICAL: `r_s` never reaches the deformation; the sweep has no scale axis

### A-3 — CRITICAL: raw σ is reported as Δσ; the α = 0 baseline is never subtracted

`compute_delta_sigma()` (line 107) is named for a baseline-subtracted quantity and its own
docstring concedes it is not one:

> "For simplicity, we use the null directly and measure deviation."

It returns `σ = (β₁_deformed − null_mean) / null_std` — a raw deviation against the
undeformed null. Directive **E2.11** mandates `Δσ(A) = σ(A) − σ(0)`. The deliverable
template then labels this quantity **"|Δσ|"** at doc lines 314, 318 and 322, and the zone
boundaries are applied to it.

Measured consequence, same run as A-2:

```
amplitude=0 is exact identity: True
sigma at ZERO deformation = +3.00   <-- labelled 'delta_sigma' in the deliverable
```

`void_to_filament_deformation` returns the input exactly at `amplitude=0` (verified:
`np.array_equal` → `True`). So **σ = +3.00 is measured on an undeformed field** and lands
exactly on the `ZONE_1_BOUNDING_BOX` boundary (`|σ| ≥ 3.0`). Every cell from α = 0.0 through
α = 1.0 would be classified `ZONE_1_BOUNDING_BOX` — **25 of 48 grid points**, all of them
reporting a "bounding box" derived from a field nothing was done to. The single cell where
the deformation visibly acts (α = 2.0, σ = −0.33) reads as *less* significant than the
untouched field.

This is the WP-E2 finding (44/72 detections at A = 0) reproduced exactly, and the **fourth
occurrence** of the tautological-pass class after WP-R3, WP-H and WP-E3.

### A-7 — MEDIUM: the statistic is near-degenerate at these settings

### A-8 — LOW: `resolvable_2d` fails open on a degenerate field

`pipeline/transverse.py:194` divides by `nbins` with no guard on a zero extent. A degenerate
slice (all objects at one RA) gives `voxel_x = 0` → `scale/0 = inf` → `inf >= min_voxels` →
verdict **`RESOLVABLE`**. The safety guard returns its most permissive verdict on its most
degenerate input. Unreached in practice on the current catalogues, but this function is the
mechanical guard E2.16 makes mandatory, so it should fail closed.

## 5. Phase 1 (`wpe_closure_tests.py`) — audited after the fact, three findings

Added 2026-07-26 after completing the built-but-unrun work. Phase 1 was in the same state as
the sweep: **written, committed, never executed.**

### B-1 — CRITICAL: the same crash as A-1

Line 59 called `density_shuffle_realization(field_undeformed, rng=rng)` against the
`(field, seed)` signature. Identical defect, identical consequence: the script had never run.
Fixed; each realization now takes its own seed.

### B-2 — HIGH: the false-positive test could not fail

`test_null_false_positive_rate` declared `alpha = 0.05` and then counted exceedances at
**|σ| ≥ 5.0**. Those are not the same criterion: a 5σ two-sided cut corresponds to
α ≈ 5.7 × 10⁻⁷, not 0.05 — the bound was built for a nominal rate **five orders of magnitude
looser** than the rule actually applied, giving an upper bound of 12.31% on a quantity expected
to be ~0. Fixed by *deriving* the nominal α from the σ threshold in use, so the two cannot
drift apart again. The corrected bound is 2.55 × 10⁻⁴, and the test now **fails** on the real
configuration (1 exceedance in 80).

### B-3 — MEDIUM: only booleans were persisted

The JSON recorded `{"closure": true}` and nothing else — no σ, no null statistics, no β₁. The
artifact could not be audited, which is the failure WP-E3 was supposed to have settled ("the
JSON is the artifact, the print is a convenience"). Each test now returns its measured detail
and the JSON carries it, including `null_distinct_values` so degeneracy is visible.

### Phase 1 result, once it could run: **FAIL** (exit 1), and correctly so

| test | result |
|---|---|
| closure (α = 1.0) | **FAIL** — β₁ = 0 deformed *and* undeformed; Δσ = 0. The pipeline cannot recover a signal it injected itself at 200 objects. |
| negative control (α = 0) | PASS — identity bit-exact, \|σ\| = 0.28 |
| null FPR | **FAIL** — 1/80 at 5σ vs bound 2.55 × 10⁻⁴; null bank takes **2 distinct values**, so σ is not Gaussian-interpretable |

Both failures are informative rather than defects in the test: they say the statistic has no
sensitivity at this occupancy, which is the same conclusion Phase 0 reached on real data and
which the Phase 2/3 sweep then quantified (detection needs n ≈ 5000, ~27× the real slice).

zero cost, and is worth adding.
